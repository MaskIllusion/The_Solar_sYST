# 🌌 Solar System Explorer

Интерактивное 3D-приложение для изучения Солнечной системы.

## Функционал
- 3D-сцена с планетами, спутниками и астероидами
- Вращение, зум, клик для информации
- Поиск планет
- Регулировка скорости

## Технологии
- Three.js
- JavaScript
- CSS3

## Запуск
1. Скачать index.html
2. Открыть в браузере
